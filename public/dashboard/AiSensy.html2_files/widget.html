Feature Suggestions for Live Chat Dashboard

We’ve been using the live chat dashboard actively and wanted to share some feedback: Colour Coding for Agents: It would be helpful if each agent had a unique colour tag when they view or respond to chats. This would make it easier to track who handled what and help agents quickly identify their own chats. Chat Labels (Similar to WhatsApp): Having the ability to add custom labels like “High Priority,” “Follow-Up,” or “New Lead” would really help in organizing and tracking chats more effectively. Seen but Unreplied Notifications: A notification to alert agents when a chat has been seen but not replied to would help prevent missed follow-ups. Follow-Up Reminders: Automated reminders for agents to follow up on chats where the customer hasn’t responded would help maintain continuity. Template Editing: Currently, we’re unable to edit existing templates. It would be helpful if we could edit existing text/media templates for quick corrections or updates. Unsend Option for Media & Messages: An option to unsend media or text messages (in case of errors or incorrect files) would be very helpful. ChatGPT Integration: Integrating ChatGPT into the chat panel could help agents rephrase replies or check grammar before sending — especially useful in high-pressure scenarios. Editable Attributes in Chats: Currently, editing an attribute replaces the existing one. It would be great if we could modify attributes without losing previous values. Live Agent Reports: Having real-time reports of agent activity (such as response times, number of chats handled, etc.) would support better team performance tracking. We really appreciate the platform and just wanted to share these thoughts as regular users. Thank you for all your support!
